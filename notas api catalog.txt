Ejercicio 4. API para catálogo de libros
Aprendiz: ANDERSON ORREGO BEDOYA
Desarrollar una API para administrar información bibliográfica.
Actividades:
1. Registrar libros.
2. Consultar todos los libros.
3. Consultar un libro por ID.
4. Actualizar la información de un libro.
5. Investigar e implementar un filtro para consultar libros según su categoría.
6. Eliminar libros.
Datos: ID, título, autor, editorial, año de publicación y categoría.
